# 합의도 뱃지 + 로드맵 커버리지 점수 — 설계

날짜: 2026-07-07
상태: 승인됨
데이터 기반: 대교협 「2028학년도 권역별 대학별 권장과목」(2026-02-20, `university-recommendations.json`, 47개교·1,358개 모집단위)

## 목적

계열별 추천이 "범용이라 부정확하다"는 인상을 "범용인데 근거가 투명하다"로 바꾼다.
추천 과목마다 몇 개 대학이 실제로 요구하는지 보여주고(뱃지), 로드맵 설계가 대학
핵심과목을 얼마나 커버하는지 실시간 피드백한다(게이지). 목표 대학 오버레이는 이번
범위에서 제외.

## 1. 데이터 레이어

`app/src/data/university-recommendations.ts`에 함수 하나 추가:

```ts
export interface ConsensusBadge { core: number; recommended: number; }
export function getConsensusBadges(interests: string[]): Map<string, ConsensusBadge>
```

- 과목명 → 그 과목을 **명시적으로** 핵심/권장과목으로 지정한 대학 수 (대학명 기준 중복 제거).
- 우산 용어(`areas`: "수학", "과학" 등) 확장은 **카운트에서 제외** — "핵심 N개교"라는
  표기가 문자 그대로 참이어야 하므로. 기존 추천 보강(coreOnly)과 같은 보수 기준.
- 내부적으로 기존 `getEntriesByInterest`(태그→모집단위 키워드 매칭 + crosstalk 제외)를 재사용.
- 뱃지와 커버리지 모두 이 함수 하나로 계산한다.

## 2. 합의도 뱃지 (추천 화면 `recommend/page.tsx`)

- 과목 카드에 `핵심 N개교 · 권장 M개교` 뱃지. N 또는 M ≥ 1일 때만 표시, 0인 쪽은 생략.
- 카운트는 선택한 관심계열 기준 — 같은 과목이라도 관심계열이 다르면 숫자가 다르다(의도됨).
- 목록 상단 각주: 대학 수는 대교협 「2028학년도 권역별 대학별 권장과목」에서 해당 계열
  모집단위 기준임을 명시.

## 3. 커버리지 게이지 (로드맵 화면 `roadmap/page.tsx`)

- 상단 sticky 게이지, 과목 추가/제거 시 실시간 갱신.
- **분모**: 관심계열에서 핵심과목 지정 대학이 3개교 이상인 과목 중 우리 학교 개설 과목.
- **분자**: 분모 중 현재 로드맵에 담긴 과목.
- 빠진 과목: 핵심 지정 대학 수 내림차순 최대 3개 칩 — "⚠ 빠짐: 기하(10개교)".
- **미개설 핵심과목(3개교 이상)은 분모에서 제외하고 별도 회색 안내** —
  "우리 학교 미개설: 기하(10개교 핵심) — 공동교육과정 등 확인". 학생이 어쩔 수 없는
  과목으로 점수를 깎지 않되 정보는 숨기지 않는다.
- 게이지 숨김 조건: ① 관심계열 없이 학과명(dept)으로만 진입 ② 분모 0.

## 4. 검증·배포

- `npm run lint` + `npm run build` (app/) 필수 체크.
- 효자고 버전(이 브랜치 `app/`)에서 화면 확인 → 커리컴퍼스(clean 브랜치 `generic-app/`)에
  포팅. 커리컴퍼스는 공유 뷰(`/s/[shareToken]/recommend`, `/roadmap`) 구조라 포팅 시
  페이지 구조 차이를 별도 확인한다.

## 범위 밖

- 목표 대학 오버레이 (3번 기능, 추후)
- 3단 등급 변환·툴팁 대학 목록 (뱃지는 숫자 그대로)
- dept 진입 경로의 게이지 (관심계열 매핑이 없어 1차 제외)
