# 로드맵 저장/공유 + 이미지 내보내기 + 학과 비교 설계서

## Context
효자고 선택과목 도우미 서비스의 핵심 페인포인트 해결:
1. 로드맵을 만들어도 페이지를 나가면 선택이 사라짐
2. 수강신청서에 옮겨 적는 과정이 번거로움
3. 여러 학과를 비교하며 고민하기 어려움

교사 시연 + 학생 셀프서비스 양쪽에서 활용.

---

## A. 로드맵 저장 & 공유

### 동작 방식
선택 데이터를 URL 쿼리 파라미터에 압축 인코딩. DB 불필요.

### 인코딩 설계
각 선택군(group)의 선택값을 인덱스 배열로 변환 후 base64url 인코딩.

```
selections = { "2026_g2_s1_tech": ["일본어"], "2026_g2_s1_cross": ["세계사", "사회와 문화", ...], ... }
→ 각 group의 options 배열에서 선택된 항목의 인덱스 추출
→ groupId별 인덱스를 콤팩트 문자열로 직렬화
→ base64url 인코딩
→ /roadmap?c=2026&interests=cs-ai&s=encodedString
```

### URL 구조
```
/roadmap?c={cohort}&dept={deptName}&interests={tagIds}&s={encodedSelections}
```
- `c`: 코호트 (2025 or 2026)
- `dept` 또는 `interests`: 추천 소스 (기존과 동일)
- `s`: 인코딩된 선택 데이터 (신규)

### UI
- 로드맵 하단에 "공유하기" 버튼 추가
- 클릭 시:
  1. 현재 선택을 URL에 인코딩
  2. navigator.share API 시도 (모바일 공유 시트)
  3. 실패 시 클립보드 복사 + 토스트 알림
- 공유 링크로 접속하면 자동으로 선택 상태 복원

### 로드맵 페이지 초기화 우선순위
1. URL에 `s` 파라미터 있으면 → 디코딩하여 선택 복원
2. 없으면 → 기존 자동 추천 로직 실행

### 파일 변경
- `app/src/app/(main)/roadmap/page.tsx`: 인코딩/디코딩 로직, 공유 버튼 UI
- 별도 유틸 불필요 (페이지 내 함수로 충분)

## B. 로드맵 이미지 내보내기

### 동작 방식
html2canvas로 로드맵 콘텐츠 영역을 PNG 캡처 후 다운로드.

### 라이브러리
`html2canvas` (npm install html2canvas)
- 클라이언트 사이드 전용, 서버 불필요
- 모바일 브라우저 호환

### 캡처 영역
- 학교 로고 + "효자고등학교 나의 수강 로드맵" 제목
- 학년별 선택 과목 요약 (학기별 지정과목 + 선택과목)
- 학점 합계

sticky 헤더와 학점 바는 캡처용 별도 div로 렌더링 (sticky 요소는 html2canvas에서 문제 발생 가능).

### UI
- 로드맵 하단 "공유하기" 옆에 "이미지 저장" 버튼
- 클릭 시 캡처 → PNG 다운로드
- 파일명: `효자고_로드맵_{코호트}.png`

### 파일 변경
- `package.json`: html2canvas 의존성 추가
- `app/src/app/(main)/roadmap/page.tsx`: 캡처용 ref + 내보내기 함수 + 버튼

## C. 학과 비교

### 동작 방식
2~3개 학과를 선택하고 추천 과목의 공통/차이를 테이블로 비교.

### 진입점
- 홈 화면 검색에서 "비교" 모드 진입 (학과 여러 개 선택)
- 또는 추천 페이지에서 "다른 학과와 비교" 버튼

### 비교 화면 구성
1. 선택된 학과 2~3개 칩 표시 (제거 가능)
2. 비교 테이블:
   - 행: 과목명
   - 열: 각 학과
   - 셀: 추천 여부 (O/X 또는 카테고리 표시)
   - 공통 추천 과목 상단 강조
3. 하단: "이 과목들로 로드맵 만들기" (공통 과목 기반)

### 데이터
- `getDepartmentRecommendation()` 을 학과별로 호출
- 결과를 합쳐서 과목별 추천 학과 수 계산

### 라우팅
- `/recommend?compare=학과1,학과2,학과3`
- 추천 페이지의 새로운 모드로 구현 (별도 페이지 불필요)

### 파일 변경
- `app/src/app/(main)/page.tsx`: 비교 모드 진입 UI (학과 복수 선택)
- `app/src/app/(main)/recommend/page.tsx`: 비교 모드 렌더링 추가
