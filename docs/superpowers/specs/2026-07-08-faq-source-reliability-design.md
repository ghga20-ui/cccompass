# 추천 근거 인라인 설명 + FAQ 페이지 — 설계

날짜: 2026-07-08
상태: 승인 대기
배경: 전국 확산으로 "권장 과목의 출처·자료 신뢰도" 문의가 반복됨. 질문이 생기는
지점(추천 화면)에서 즉답하고, 상세는 독립 FAQ 페이지로 응대 부담을 줄인다.

## 목적

추천의 근거·데이터 출처를 사용자가 스스로 확인할 수 있게 해 신뢰도 문의를 예방·응대.
새 데이터·계산 로직(대교협 뱃지, 커버리지 게이지, 교차 검증)이 이미 갖춰졌으므로,
그 근거를 화면 언어로 노출하는 작업.

## 구성 (C안: 인라인 + 독립 페이지)

### 파트 1 — 추천 화면 인라인 접이식

- 위치: 추천 결과 상단(선택 계열/요약 근처). recommend 페이지의 InterestRecommendContent와
  DeptRecommendContent 양쪽.
- 기존 `CompetencyAccordion`과 동일한 접이식 UI 패턴을 따른다(신규 스타일 도입 없음).
- 제목: **이 추천은 어떤 근거로 만들어졌나요?**
- 펼친 내용(3~4항목):
  - 계열별 추천 과목은 **2022 개정 교육과정 선택 과목 안내서**를 바탕으로, 대학이 실제
    요구하는 과목과 대조해 구성했습니다.
  - 과목에 붙은 **「핵심 N개교」** 뱃지는 한국대학교육협의회(대교협) 「2028학년도 권역별
    대학별 권장과목」(전국 47개 대학)에서 그 과목을 지정한 대학 수입니다.
  - 뱃지가 없는 과목은 대입 반영과목은 아니지만, 탐구활동·세부능력특기사항 등 **역량을
    보여주기에 좋은 과목**입니다.
  - **자료 출처와 자주 묻는 질문 →** (`/faq` 링크)

### 파트 2 — 독립 FAQ 페이지 (`/faq`)

- 효자고(`app/`)·커리컴퍼스(`generic-app/`) 양쪽에 새 라우트 `/faq`.
- 아코디언 Q&A. 진입: 푸터 "자료 출처" 근처 링크 + 파트 1 접이식 링크.
- 학교 비종속(school-agnostic) 콘텐츠라 share-scope 밖 top-level 라우트로 둔다(/guide와 동일).

#### FAQ 카피 전문

**Q1. 추천 과목은 어떤 자료를 근거로 하나요?**
두 가지 자료를 씁니다. ① 계열별 추천 과목의 뼈대는 「2022 개정 교육과정 선택 과목
안내서」입니다. ② 각 과목이 대학에서 얼마나 요구되는지는 한국대학교육협의회(대교협)가
발표한 「2028학년도 권역별 대학별 권장과목」(전국 47개 대학)과 대조해 확인합니다. 두 자료를
교차 검증해, 안내서가 추천하지만 대학 요구 근거가 없는 과목과 대학이 요구하지만 빠진
과목을 점검했습니다.
- (효자고 변형: "안내서" → "서울진로진학정보센터의 「2022 개정 교육과정 선택 과목 안내서」")
- (커리컴퍼스 변형: "각 학교가 올린 편제표와 교육과정 안내서")

**Q2. 과목에 붙은 「핵심 N개교」·「권장 M개교」는 무슨 뜻인가요?**
선택한 계열의 모집단위를 기준으로, 대교협 자료에서 그 과목을 '핵심과목'(필수적 이수 권장)
또는 '권장과목'으로 지정한 대학의 수입니다. 예를 들어 「핵심 15개교」는 그 계열에서 15개
대학이 해당 과목을 핵심과목으로 제시했다는 뜻입니다. 뱃지가 없는 과목은 대입 반영과목
목록에는 없지만, 탐구·역량 강화에 도움이 되는 추천 과목입니다.

**Q3. 로드맵의 '대학 핵심과목 N%'는 어떻게 계산되나요?**
선택한 계열에서 여러 대학(3개교 이상)이 핵심과목으로 꼽은 과목 중, 우리 학교에서 들을 수
있는 과목을 기준(분모)으로, 현재 로드맵에 담은 과목의 비율입니다. 학교에 개설되지 않은
과목은 계산에서 빼되 따로 안내합니다.

**Q4. 이 추천만 따르면 대학에 갈 수 있나요?**
아닙니다. 대교협 자료는 「필수 이수 기준」이 아니라 참고용 안내이며, 대교협도 이를
명시하고 있습니다. 실제 지원 대학·학과의 최신 모집요강을 반드시 함께 확인하세요. 이
서비스는 3년간의 과목 선택 로드맵을 설계하는 데 방향을 잡아주는 도구입니다.

**Q5. 자료는 언제 기준이고 얼마나 자주 갱신되나요?**
현재 반영과목 자료는 대교협이 2026년 2월 발표한 「2028학년도 권역별 대학별 권장과목」
기준입니다. 이 자료는 확정본이 아니라 대학별 발표에 따라 수시로 갱신되므로, 대학 수·과목은
이후 변동될 수 있습니다.

**Q6. 우리 학교에 없는 과목이 추천되면 어떻게 하나요?**
공동교육과정(다른 학교·거점센터에서 수강), 온라인학교, 소인수 과목 개설 요청 등을 학교
선생님과 상담해보세요. 로드맵의 커버리지에서도 '우리 학교 미개설' 과목을 따로 표시합니다.

**Q7. (커리컴퍼스만) 우리 학교도 등록하려면?**
학교 선생님이 편제표(교육과정 편성표) 파일을 올리면 그 학교 전용 추천 화면이 만들어집니다.
홈 화면의 '편제표 올리고 시작하기'에서 진행하세요.

### 데이터/카피 관리

- FAQ 항목은 페이지 컴포넌트 내 배열 상수로 관리(별도 데이터 파일 불필요, YAGNI).
- 효자고/커리컴퍼스 차이는 Q1·Q7 두 항목뿐 → 각 앱의 페이지 파일에서 해당 문구만 다르게 둔다.

## 검증·배포

- `npm run lint` + `npm run build` (app/), `npx pnpm run build` (generic-app/).
- 효자고는 codex→main 머지로 배포, 커리컴퍼스는 clean 브랜치 푸시로 배포(각각의 경로).
